# LinguaLand · 语言奇遇岛

面向小学三至六年级的英语巩固练习网站。技术栈：Vue 3 + TypeScript + Vite，部署于 GitHub Pages。

## V2.1 教材知识提取与配套练习重建
- 已依据用户上传的《英语 三年级上册 2024 版》（译林出版社）核对上册八个单元的教学目标、字母范围与书后 Word lists（印刷页 78–79）。
- 上册替换原先的主题猜测数据，接入 **120 张书后 Word lists 对应词卡、225 道原创基础练习**，并新增单元导学页，包含学习目标、字母、重点表达与原创情景对话。
- 新数据：`src/content/2024-g3a-verified.json`；下册暂继续使用 V2.0 未核验的原创主题数据。
- 教材原有插图、故事原文及音频不直接复制到网站；单词的例句、对话和练习均为原创配套内容。教材中的词汇和常用表达不意味着网站练习来自官方题库。
- 旧版同名题目 ID 已保留为独立命名空间，历史学习记录不会因内容替换而直接丢失；但旧内容的题目掌握度不自动转移到新题目。

## V2.0 内容建设（第一批）

- 以用户确认的 **2024 修订版译林英语三年级上、下册**为目录基准：共 16 个 Unit，分别为上下册各 8 个单元。
- `src/content/2024-g3-manifest.json`：版本、单元名称与主题；`src/content/2024-g3-practice.json`：配套原创练习数据。
- 第一批提供 **128 张主题词卡、256 道原创基础练习题**，用于丰富学习体验并验证内容数据管线。**这些词汇、例句与题目不是经过逐页核对的教材官方内容**，不得将其视为教材词汇表或原文。
- 既有三个示范单元保留在单独的“原创示范”课程中，历史学习进度不丢失。
- 待取得合法教材资料并逐条核验后，再标记教材来源、词汇级别、重点句型、Project、课文与音频授权信息；正式内容不应通过猜测填充。

## V1.6 功能

- 森林主题响应式首页、学习地图与星星奖励
- 单词闪卡、浏览器语音朗读

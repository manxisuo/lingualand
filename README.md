# LinguaLand · 语言奇遇岛

面向小学三至六年级的英语巩固练习网站。技术栈：Vue 3 + TypeScript + Vite，部署于 GitHub Pages。

## V2.0 内容建设（第一批）

- 以用户确认的 **2024 修订版译林英语三年级上、下册**为目录基准：共 16 个 Unit，分别为上下册各 8 个单元。
- `src/content/2024-g3-manifest.json`：版本、单元名称与主题；`src/content/2024-g3-practice.json`：配套原创练习数据。
- 第一批提供 **128 张主题词卡、256 道原创基础练习题**，用于丰富学习体验并验证内容数据管线。**这些词汇、例句与题目不是经过逐页核对的教材官方内容**，不得将其视为教材词汇表或原文。
- 既有三个示范单元保留在单独的“原创示范”课程中，历史学习进度不丢失。
- 待取得合法教材资料并逐条核验后，再标记教材来源、词汇级别、重点句型、Project、课文与音频授权信息；正式内容不应通过猜测填充。

## V1.6 功能

- 森林主题响应式首页、学习地图与星星奖励
- 单词闪卡、浏览器语音朗读
- 词义选择、单词拼写、短语选择、句子排序
- 统一判题、错题回顾、浏览器本地进度持久化
- 新增语言探索工坊：短语、句式、情景对话
- 智能复习计划：根据每题作答结果计算下次复习时间，支持按单元执行今日复习
- 学习分析：全课程待复习题数、掌握数量、复习计划覆盖率与单元统计
- 保留 V1～V1.5 的旧记录；无时间戳的历史答题不参与间隔时间推断
- 听说探险岛：听音选词、听音辨义、浏览器语音识别跟读及手动跟读降级
- 语音识别仅做文字匹配，不构成专业发音评分；依赖浏览器支持和麦克风权限
- 探险家成长档案、等级、6 枚成就徽章、连胜额外星星奖励
- 修复无对应题型时后续关卡解锁逻辑
- 三站式游戏关卡：启程小径、拼写溪谷、句式高地
- 关卡按答题正确率评定 1～3 星，解锁后续关卡并持久化最佳成绩
- 课程地图：年级、学期、单元选择及独立学习进度
- 新增两个原创示范单元，保留旧示范单元学习记录
- 森林场景微动效、键盘焦点可见性与减少动画支持

当前使用 **三个原创示范单元** 验证产品体验，尚未接入经核对的译林版教材原文。当前目录不对应正式译林版教材，后续可按教材版本、年级、学期和单元扩充。

## 本地开发

```bash
npm install
npm run dev
npm run build
```

## GitHub Pages

仓库 `manxisuo/lingualand` 的 Vite base 为 `/lingualand/`。GitHub Pages 的 Source 应设置为 **GitHub Actions**。推送 main 后自动构建并部署。

访问地址：https://manxisuo.github.io/lingualand/

## 注意

学习记录默认保存在当前浏览器的 localStorage 中，不支持跨设备同步。发音由浏览器 Speech Synthesis 提供，效果依赖系统语音包及浏览器支持。
